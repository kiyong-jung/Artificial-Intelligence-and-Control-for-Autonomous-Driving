## 요약

- 학습 환경(`env/`)에는 배경 차·보행자·신호에 내리는 TraCI 명령이 없다. 명령은 모두 ego 버스에게 간다(정적 검사).
- 학습 환경을 전문가 정책으로 15회(교통량 3종 × seed 5) 돌렸다. 순간이동 0, 충돌 0, 버스 50m 안 차량 출현 0,
  15회 모두 완주, 정류장 60/60 정차. 182초(가장 긴 신호 주기)보다 오래 선 차는 없다.
- 학습 환경에 남은 문제는 감추는 설정이다. 배경 차끼리 부딪히면 SUMO가 두 대를 지우고(`collision.action remove`),
  경고를 꺼서(`--no-warnings`) 비상 제동이 기록에 남지 않는다. 비상 제동은 에피소드마다 1~5번 났고 모두 배경 차였다.
- 주변 교통 경로(`traffic/`)는 busy seed 3에서 J82 교차로가 막혀 버스가 2,042초 서 있었다(다른 에이전트가 고치는 중).
  나머지 5회는 3바퀴를 돌았고 순간이동과 충돌이 없다.
- 두 경로는 서로 다른 세상이다. 적분 방식, 충돌 처리, 우회전 신호, 보행자 유형, 배경 버스·택시, 운전자 성향이 다르다.
- 지도에는 시나리오 수요를 손으로 키운 흔적이 남아 있다(골목 3배, S6 보행자 4배, 15초마다 한 명).

## 다시 돌리는 명령

```bash
export SUMO_HOME=/Users/ky/src/sumo-1.27.1-mesa
PY=/Users/ky/miniforge3/envs/sumo-rl/bin/python
$PY scripts/audit_naturalness.py                 # 정적 검사, 1초. 표에 없는 것이 있으면 종료 코드 1
$PY scripts/audit_naturalness.py --strict        # 아래 '열림' 발견이 남아 있으면 종료 코드 1 (2회차의 목표)
$PY scripts/audit_naturalness.py --self-check    # 심어 둔 나쁜 예 20건을 잡는지
$PY scripts/audit_naturalness.py --dynamic --seeds 5 --traffic-scenarios quiet baseline busy --traffic-seeds 0 3 \
    --out results/naturalness/round1             # 이 보고서의 동적 결과(약 25분, SUMO 동시 4개)
$PY -m pytest -q tests/test_naturalness_static.py
```

결과는 `--out` 폴더의 `static.json`, `dynamic.json`, `dynamic.md`와 실행별 `sumo.log`, `statistics.xml`,
`collisions.xml`이다(`results/`는 git에 올리지 않는다).

## 검사기가 하는 일

정적 검사는 네 가지를 훑고, 찾은 것을 스크립트 안 `RULES` 표와 맞춘다. 표에 없으면 실패한다.

1. 모든 `.py`의 TraCI 변경 호출(`vehicle`, `person`, `trafficlight` 등 14개 영역에서 읽기가 아닌 메서드). 함수와 첫
   인자까지 본다. 그래서 `env/sumo_env.py`에 `setSpeed(vid, …)`가 생기면 `self.ego_id`가 아니라 실패한다.
2. `.py`의 위험한 SUMO 옵션(`collision.action`, `time-to-teleport`, `ignore-route-errors`, `no-warnings` 등)과
   속성 이름(`jmIgnoreFoeProb`, `jmDriveAfterRedTime`, `impatience`, `ignoreTypes`, `onRoad` 등).
3. 커밋된 지도 XML과, 두 경로가 실제로 만드는 실행 폴더(env 합정역·팔달문, traffic 합정역)의 XML 값.
4. 지도 모양: 안쪽 도로에서 생기는 흐름, 짧은데 차로마다 가는 길이 다른 도로, 차 우선 횡단보도, 파일에 박힌 보행자
   출발 시각, 도로 끝에 붙은 정류장, 빌드가 키운 수요.

지금 결과는 195건이다. 정당함(ALLOW) 126, 열림(OPEN) 69, 표에 없음 0.

동적 검사는 `traci.start/load/simulationStep`을 감싸 SUMO에서 읽기만 한다. 순간이동, 충돌(위치), 비상 정지, 120초
넘게 선 차와 사람(5초마다, 위치), 버스 50m 안 출현(도로 20m 지점 뒤면 '도로 한가운데')을 적고, SUMO 경고 기록에서
비상 제동을 센다. 검사기가 센 순간이동·충돌·비상 제동·비상 정지 수는 21회 모두 SUMO의 `statistics.xml`과 같았다.
