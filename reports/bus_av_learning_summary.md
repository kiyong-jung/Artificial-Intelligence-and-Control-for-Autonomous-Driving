# 합정역 버스 AV: 수업 기준 환경과 데이터 수집 준비 상태

2026-11-24 · 정기용 · 근거 브랜치 `research/av-bc-rl` · 과정 기록은 `reports/progress_log.md`

## 결론

- **수업 규칙대로 깨끗한 데이터를 모을 수 있는 상태다.** 자율주행 버스의 SUMO 안전장치를 끄고 차로 지시 정보를 뺀 조건에서, 수집 정책이 학습에 쓰지 않은 seed 60회를 모두 완주했다. 차 충돌, 보행자 충돌, 적색 통과, 순간이동, 급제동은 0이고 정류장 네 곳에 모두 섰다.
- **환경의 억지 장면과 순간이동은 없앴다.** 환경은 배경 차와 보행자에게 명령을 보내지 않는다. 버스를 빼고 돌려도 배경 차의 출발과 경로가 같다.
- **학습은 아직 하지 않았다.** 예전에 학습한 모델과 예전 데이터는 조건이 달라 쓰지 않는다. 데이터 1,000만 개 수집에 약 27~32시간이 걸린다.
- **조교 확인이 필요한 해석이 넷 있고, 도로 모양에서 오는 어색한 장면이 몇 가지 남아 있다.**

## 1. 수업 기준과 우리 설정

| 수업 기준(수업 저장소) | 지금 설정 |
|---|---|
| 보조 규칙, 규칙 기반 도움 금지 | 환경이 버스 속도에 끼어든 스텝 0. 보정 강화학습(규칙 + 학습값)은 결과에서 뺀다 |
| 자율주행 차량의 SUMO 안전장치 끔 | 끔(speedMode 0, laneChangeMode 0) |
| 경로는 큰 틀만, "어느 차선으로"는 금지 | 차로 지시값 셋을 관측에서 뺌(43차원) |
| 충돌률 5% 미만, 완주 | 최종 seed 60회 충돌 0, 완주 60/60 |
| 순간이동, 비정상 정체 없음 | 순간이동 끔. 막히면 "갇힘"으로 세며 60회 중 0 |
| 일반 차량이 충분하고 버스 행동에 영향 | 교통량 1.25배. 배경 차 유무에 따른 한 바퀴 차이 1.6초에서 36.3초 |
| 데이터 1,000만 개 이상 | 미수집. 초당 약 100개, 27~32시간 예상 |

- 이 60회 데이터의 컬럼, 빈 값, 범위 오류는 0개다. 같은 seed로 다시 모으면 한 행도 다르지 않다.
- 경고 기록에 배경 차량 충돌과 순간이동은 없다. 인도에서 보행자끼리 부딪힌 경고가 1건 있다.
- 전속력으로만 달리는 버스는 7번 모두 적색 통과나 충돌로 끝났다. SUMO가 대신 세워 주지 않는다는 뜻이다.
- 수집 정책은 관측만 쓴다. 저장된 관측으로 행동 1,098개를 다시 계산해 모두 같았다.

## 4. 남은 것

**조교 확인(11/24 컨설팅)**

1. 규칙 운전 기록을 모방학습 데이터로 써도 되는가. 수업 흐름은 학습한 모델로 모으는 것이다.
2. 관측의 "이 차로가 버스 노선으로 이어지는가"(200m 앞까지)가 허용되는가. 원본은 50m 안에 아무 연결이나 있으면 1이다.
3. 차로를 바꾸는 도중 옆 차가 들어오면 환경이 변경을 되돌려도 되는가.
4. S6 횡단보도에 보행자의 34%(시간당 240명)를 둔 수요를 밝히고 써도 되는가.

**도로와 SUMO 한계(고치려면 도로망이나 신호를 손봐야 함)**

- 와우산로 골목 교차로에서 큰길 차가 골목에서 나온 차를 겹친 채 지나간다(SUMO는 충돌로 세지 않음).
- J96 합류부: 버스 없이 400회 돌리면 배경 충돌이 6~8번 난다. 교통량을 1.25배보다 더 올리지 못하는 이유다.
- J42 이중 좌회전에서 12m 버스가 옆 차와 최대 0.5m 겹친다.
- R42의 한 차로가 직진과 좌회전을 같이 써서 버스가 직진 대기 차 뒤에서 최대 58초 기다린다.

**다음 순서**

1. 조교 답에 따라 2번과 3번을 고치고 다시 잰다.

3. 그 데이터로 모방학습을 하고, 강화학습은 수업 기준 환경에서 처음부터 한다.
