# 과제: 합정역 자율주행버스의 규칙 정책 정상화와 BC, PPO, Residual RL 비교

AI-Scientist-v3(The Agentic Scientist)의 단계를 따른다. 과제 정의 → 탐색(아이디어 사이클) → 어블레이션 → 봉인된 최종 평가 → 사후 분석 → 보고서. 이 Mac에는 Docker와 GPU가 없어 `agsci run`은 쓰지 않고, 같은 단계와 산출물을 이 폴더에 둔다.

## 목표

1. 주변 차량과 보행자가 시나리오를 억지로 만드는 코드를 찾아 자연스러운 행동으로 바꾼다.
2. 규칙 기반 버스(전문가 정책)가 이상하게 움직이지 않게 고친다. 신호 앞 급정지, SUMO 안전 보조 개입, 행동과 실제 움직임의 불일치를 없앤다.
3. 고친 전문가 정책으로 BC 학습 데이터를 모은다.
4. BC, PPO, Residual RL(전문가 행동 + 학습한 보정)을 학습하고, 학습에 쓰지 않은 seed에서 닫힌 루프로 주행시켜 비교한다.

## 제약

- 지도는 합정역 3.13.0 도로망(`maps/hapjeong/source/network.net.xml`)과 `bus_loop`(1,949m)다.
- 정책 입력은 정책이 실제로 볼 수 있는 값만 쓴다. 전문가 정책도 같은 관측만 써야 BC가 따라 할 수 있다.
- SUMO 안전 보조는 마지막 방어선으로 남기되, 개입한 비율을 지표로 잰다. 좋은 정책은 개입이 거의 없어야 한다.
- 커밋은 사용자 이름으로만 한다. 팀원 코드(`traffic/`)를 바꾸면 따로 커밋하고 이유를 남긴다.

## 평가(평가기: `evaluate.py`, 지표: `behavior_metrics.py`)

닫힌 루프 주행을 고정 seed 집합에서 돌리고 에피소드마다 다음을 잰다.

| 지표 | 뜻 |
|---|---|
| 완주율, 충돌, 순간이동 | 안전과 완주 |
| 바퀴 시간, 평균 속도 | 운행 효율 |
| 급제동(속도 기준 3m/s² 초과) 횟수, 최대 감속 | 승차감과 안전 |
| SUMO 속도 개입 비율 | 정책이 스스로 안전하게 달리는지 |
| 행동-움직임 불일치 비율 | 가속 명령 중 실제 감속(BC 라벨 품질) |
| 설명 없는 정지, 30초 넘게 갇힘 | 이상 주행 |
| 차선 변경 왕복, 거절된 변경 | 이상 주행 |
| 정류장 정차 수 | 버스 운행 |

seed 집합은 셋으로 나눈다. 탐색과 튜닝은 `dev`(1000번대), 학습 데이터는 `train`(2000번대), 최종 평가는 `final`(9000번대)이다. `final`은 최종 평가 단계 전에는 돌리지 않는다.
